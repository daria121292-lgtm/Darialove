# Создание рейса — вариант 8

Интерактивная демонстрация: доставки и маршрут → транспорт и подача → запрос транспорта. Верхних шагов и отдельного предпросмотра нет. Все данные вымышленные; реальные заявки не отправляются.

- [Начать с 50 доставок](https://daria121292-lgtm.github.io/Darialove/variant-8/?example=start)
- [Посмотреть распределённые 200](https://daria121292-lgtm.github.io/Darialove/variant-8/?example=distributed)
- [Большой рейс: 600 доставок](https://daria121292-lgtm.github.io/Darialove/variant-8/?example=large)
- [Пункт с ответственным](https://daria121292-lgtm.github.io/Darialove/variant-8/?example=start&pointMode=responsible)
- [Изменение запроса до принятия](https://daria121292-lgtm.github.io/Darialove/variant-8/?example=requested)

Внутри доступны массовый выбор, вставка списка, назначение пути группам, услуги по остановкам, вывоз после развоза, автоматические суммы веса и объёма, сохранение примера в браузере. Кнопка «Скачать HTML» сохраняет автономную демонстрацию.

Прототип — гипотеза для проверки. Реальные бизнес-правила, договоры, статусы и интеграции не реализованы. Предыдущие варианты сохранены отдельно.
